# Media

Drop your own artwork here. Everything shipped in this folder is generated
placeholder work, so nothing has to be removed for licensing reasons before you
deploy.

| File | Used by | Notes |
|---|---|---|
| `hero-default.svg` | `Hero` on the landing page | Replace with a wide image, 1600×900 or larger. Cream text sits over the left half, so keep that side uncluttered. |
| `logo.svg` | `SiteHeader` | Square. Falls back to a lettermark when absent. |

## Where to get artwork you can actually use

**Your own screenshots.** You run the server; screenshots you take in your own
client are the usual source for a realm site, and they show your realm rather
than someone's marketing.

**Your own logo.** A realm name set in a display face is enough, and it is the
one thing that should not look borrowed.

## What not to put here

Artwork, video, logos or fonts taken from Blizzard's site. The World of Warcraft
logo is a trademark, and this CMS is meant to be installed by other people — a
copied asset becomes their problem as well as yours. The footer already carries
a "not affiliated" notice for the same reason.
